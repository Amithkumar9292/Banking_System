# 💰 Banking System (Java - Swing + OOP)

A simple and interactive **Banking System application** developed using **Java Swing** that demonstrates core **Object-Oriented Programming (OOP)** and **Advanced Java concepts** like abstraction, inheritance, polymorphism, interfaces, event handling, and the `final` keyword.

---

## 🚀 Features

* 🏦 Supports **Savings Account** and **Current Account**
* 📊 Calculates **interest automatically**
* 🎯 Demonstrates use of **final method** (prevents overriding)
* 🧩 Implements **OOP concepts**:

  * Abstraction
  * Inheritance
  * Polymorphism
  * Encapsulation
* 🖥️ User-friendly **Graphical User Interface (Swing)**
* ⚡ Event handling using **ActionListener**

---

## 🧠 Concepts Used

* Java Swing (GUI)
* Event Handling (Source, Event, Listener)

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Amithkumar9292/Banking_System.git
```

2. Navigate to the project folder:

```bash
cd Banking_System
```

3. Compile the program:

```bash
javac Main.java
```

4. Run the program:

```bash
java Main
```

---

## 💡 How It Works

* User enters **balance** and **interest rate**
* Selects account type:

  * Savings → earns full interest
  * Current → no interest (real-world behavior)
* Clicks **Calculate**
* System displays the calculated interest

---

## 🎯 Key Highlight

The method:

```java
public final double calculateInterest()
```

cannot be overridden in derived classes, ensuring **consistent business logic** across all account types.
